# Функция B: Сумма памяти

## Цель
Посчитать суммарный объем памяти всех процессов и вывести SumMb.

## Входные данные
Основной набор: editor(400), agent(80), browser(900), monitor(200)

## Ожидаемый результат
editor; mb=400
agent; mb=80
browser; mb=900
monitor; mb=200
SumMb: 1580

## Фактический результат
editor; mb=400
agent; mb=80
browser; mb=900
monitor; mb=200
