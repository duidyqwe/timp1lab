# Инвентаризация памяти процессов

ФИО: TAVNAO
Группа: 714-1 
Вариант: 6

## Описание
Программа анализирует список процессов и их потребление памяти.

## Функции

### Функция A (feature/a)
Сортирует процессы по убыванию памяти. При равенстве — по имени по возрастанию.
Формат строки: `PROC: {Name}; mb={MemoryMb}`

### Функция B (feature/b)
Считает суммарный объем памяти всех процессов.
Сводка: `SumMb: {сумма}`

## Конфликт при слиянии
Конфликт возник в `Formatter.cs`, так как обе ветки изменили строку `return`.
- Ветка A: `return "PROC: " + item.Name;`
- Ветка B: `return item.Name + "; mb=" + item.MemoryMb;`

Объединение: `return "PROC: " + item.Name + "; mb=" + item.MemoryMb;`

## Запуск
```bash
dotnet run              # основной набор
dotnet run -- empty     # пустой массив
dotnet run -- test1     # равенство памяти
dotnet run -- test2     # нулевая память
dotnet run -- test3     # собственный тест
